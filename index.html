Data Structure A

Singly-Linked FIFO Queue (Civilian Traffic)

O(1) Enqueue / Dequeue

Civilian vehicles cannot overtake within a single-lane road approach. FLOWGRID models this physical constraint using a singly-linked node list maintaining dedicated head and tail pointers.

Live FIFO Queue Structure:
HEAD (Exit) VEH-0001 Car
⟶
VEH-0002 Bus
⟶
TAIL (Enter) VEH-0003 Truck
Invariant: First vehicle enqueued at tail is strictly the first vehicle dequeued at head.
Memory Safety: Built with C++17 std::unique_ptr<Node> to eliminate memory leaks and dangling pointers.
Data Structure B

Binary Min-Heap Priority Queue (Emergency Traffic)

O(log N) Push / Pop | O(1) Peek

Life-critical emergency vehicles preempt regular traffic. Urgency follows integer levels: Ambulance (1) > Fire Engine (2) > Police (3). Ties are broken deterministically by monotonic arrival sequence numbers.

Binary Min-Heap Tree Structure:
P1: Amb Index [0]
/\
P2: Fire Left [1]
P3: Police Right [2]
Index Formulas: Parent: ⌊(i-1)/2⌋ | Left Child: 2i + 1 | Right Child: 2i + 2.
Sifting: siftUp() restores heap invariant upon insertion; siftDown() restores it upon root extraction.
Algorithm B & C

Adaptive Signal Timing & Anti-Starvation Rule

Safety & Fairness

Fixed timers waste green cycles on empty approaches. FLOWGRID computes green duration dynamically based on approaching queue length $L$, while enforcing a strict anti-starvation policy.

Adaptive Green Duration Formula:
$$T_{\text{green}} = \text{clamp}\left(T_{\text{base}} + \left\lfloor \frac{L}{2} \right\rfloor, T_{\text{min}}, T_{\text{max}}\right)$$
$T_{\text{base}} = 4$s $T_{\text{min}} = 3$s $T_{\text{max}} = 10$s $T_{\text{yellow}} = 2$s
Starvation Prevention Rule 1: After 3 consecutive emergency vehicle dispatches, exactly 1 civilian vehicle is granted right-of-way.
Starvation Prevention Rule 2: If a civilian vehicle waits $\ge 5$ simulation steps, it receives an emergency bypass clearance.
